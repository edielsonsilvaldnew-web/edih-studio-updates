# Edih Studio — novidades

`models.json` é lido pelo Edih Studio ao abrir e a cada 6 horas.

- `version`: versão mais recente do app. Se for maior que a instalada, aparece o botão "Atualizar app".
- `models`: modelos conhecidos de cada API (`kie`, `hf`, `el`). Um `id` que o app ainda não tem aparece como "Modelo novo".
- `notes`: texto curto mostrado no aviso.
